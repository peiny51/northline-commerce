# Original eBay-derived reference notes (not indexed as Northline rules)

The original customer-support prototype used source-derived policy notes from eBay Canada. The Django commerce demo indexes the Northline demo policies in `../notes/`, **not** eBay rules, because Northline is a separate fictional store.

Original source repository files:

- [Returns](https://github.com/peiny51/e_commerce_AI/blob/main/data/policies/notes/EBAY-RETURN-001.md)
- [Cancellation](https://github.com/peiny51/e_commerce_AI/blob/main/data/policies/notes/EBAY-CANCEL-001.md)
- [Money Back Guarantee](https://github.com/peiny51/e_commerce_AI/blob/main/data/policies/notes/EBAY-GUARANTEE-001.md)
- [Item not received](https://github.com/peiny51/e_commerce_AI/blob/main/data/policies/notes/EBAY-DELIVERY-001.md)

These references can be used for **comparative policy research** or a separate evaluation corpus, but do not mix into the live Northline answer index without provenance-aware routing. Never describe eBay protections as Northline guarantees.
